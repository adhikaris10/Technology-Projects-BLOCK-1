| Component | Function |
|-----------|----------|
| SoC |It is the main processor of the Raspberry Pi. It controls and processes instructions and performs calculations. |
| GPIO |GPIO pins allow the Raspberry Pi to connect and communicate with external electronic components such as sensors, LEDs and motors. |
| USB |USB ports are used to connect external devices such as a keyboard, mouse and USB storage. |
| HDMI |HDMI port connects the Raspberry Pi to a monitor or TV to display video and audio. |
| Power |The power connector supplies electricity to the Raspberry Pi so it can operate. |
| microSD |The microSD card stores the operating system, software, files and other data. |
| Network |The Ethernet port provides a wired network connection to access the internet and communicate with other devices. |
| Wireless |Wi-Fi and Bluetooth allow the Raspberry Pi to connect to wireless networks and other wireless devices. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.
Many components are integrated into a single board in embedded computers like the Raspberry Pi to make them smaller, lighter and more efficient. It saves space and reduces the need for separate hardware components. Having the processor, memory, input and output ports, and network connections on one board makes the device easier to use and manage. It also helps reduce power consumption and overall cost. The integrated design allows different components to communicate quickly and work together smoothly. This makes the Raspberry Pi suitable for projects such as robotics, automation, education and the Internet of Things (IoT).
