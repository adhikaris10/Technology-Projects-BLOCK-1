# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |Executes instructions and processes data. |Clock speed (GHz), number of cores and threads |
| RAM |Temporarily stores data and programs currently in use. |Capacity (GB), speed (MHz), DDR generation |
| Storage |Stores the operating system, software, and files permanently. |Capacity (GB/TB), type (SSD/HDD), read/write speed |
| Motherboard |Connects all computer components and allows them to communicate. |Form factor, CPU socket, RAM compatibility, expansion slots |
| Power Supply |Converts electricity into suitable power for computer components. |Wattage (W), efficiency rating, connector types |
| Cooling |Removes heat from components to prevent overheating. |Type (air/liquid), fan size (mm), cooling capacity |
