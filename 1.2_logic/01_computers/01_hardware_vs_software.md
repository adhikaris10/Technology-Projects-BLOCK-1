# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---Hardware refers to the physical parts or components of a computer that we can see and touch. It includes all the electronic and mechanical devices that help a computer work properly. Hardware is responsible for receiving data, processing information, storing data, and producing output. Some common examples of computer hardware are the keyboard, mouse, monitor, CPU, motherboard, RAM, hard disk, printer, and speakers. Hardware works together with software to perform different tasks. Without hardware, a computer cannot function.

## Explain Software
Write **at least 50 words** explaining what software is.
---Software is a set of programs, instructions, and data that tells a computer what to do and how to perform different tasks. Unlike hardware, software cannot be physically touched or seen. It helps users communicate with computers and perform various activities. Software is mainly divided into two types: system software and application software. Examples of software include Windows, Linux, Microsoft Word, Google Chrome, and PowerPoint. Without software, computer hardware cannot perform useful tasks.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware refers to the physical parts of a computer, while software provides instructions to the hardware to perform different tasks. When a user gives a command through software, the CPU processes the instructions and the hardware performs the required operation. For example, when we type something using a keyboard, the software processes the input and displays the result on the monitor. Both hardware and software depend on each other to operate a computer efficiently.
